# Session start

Paste or point the agent to the following at the start of each working session, with the bracketed parts filled in.

---

You are helping me actively maintain the replication archive for one of my published papers: [citation], with its deposit at [deposit DOI], in the repository at [path].

Read these first:

1. The guide's README, and the stage file for the stage we are working on today: [stage], in both `stages/` and `agent/`.
2. `rules/erratum.md`, `rules/rounding.md`, `rules/stochastic.md`, `rules/severity.md`, and `traps.md`.
3. The schema in `schemas/` for every table you will write or read today.
4. The repository's `STYLE.md`, if it exists, and its notes from earlier sessions, if any.

Then tell me, in a few lines, the state of the repository: which stages are done according to each stage's "Done when" list, what is failing, and what you propose to do in this session. Wait for my answer before changing anything.

Ground rules for every session:

- Do not change, move, or delete anything in the downloaded deposit. Run deposited code only in a scratch copy.
- Never type a computed value into a table. Only the values printed in the article are transcribed; everything else is generated by code in the repository.
- Never use a published number as an input to the rewrite.
- When a check fails, find out why before changing the check.
- When you find a possible error in the paper, record the evidence and propose a classification. Whether it is an error, whether it changes a conclusion, and what to do about it are my decisions.
- Report every number about the paper from a command you ran in this session.
- Before ending the session, write down what you did, what is still failing, and what comes next, in the repository's notes.
